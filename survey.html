01 — การตรวจจับและการทำงานของ Sensor

ระบบสามารถตรวจจับการเป่าลมของผู้เข้าชมได้อย่างเหมาะสม

ระบบสามารถตรวจจับการเคลื่อนไหวของมือหรือร่างกายได้อย่างเหมาะสม

Sensor สามารถทำงานได้อย่างต่อเนื่องระหว่างการใช้งาน

ตำแหน่งการติดตั้ง Sensor มีความเหมาะสมต่อการใช้งาน

02 — การตอบสนองของระบบ

ระบบตอบสนองต่อการเป่าลมได้อย่างรวดเร็ว

ระบบตอบสนองต่อการเคลื่อนไหวของผู้เข้าชมได้อย่างรวดเร็ว

การเปลี่ยนแปลงของ Visual มีความสัมพันธ์กับการกระทำของผู้เข้าชม

การแสดงผลแบบ Real-time มีความเหมาะสม

ระบบสามารถตอบสนองต่อการปฏิสัมพันธ์ได้อย่างต่อเนื่อง

03 — การแสดงผลและ Interactive Visual

การเปลี่ยนแปลงของแบบจำลองปอดสอดคล้องกับการปฏิสัมพันธ์

การเคลื่อนที่ของ Particle ควันสอดคล้องกับการเคลื่อนไหวของมือหรือร่างกาย

Visual สามารถแสดงผลลัพธ์ของการปฏิสัมพันธ์ได้อย่างชัดเจน

การทำงานร่วมกันระหว่าง Sensor และ Visual มีความเหมาะสม

04 — ประสบการณ์ของผู้เข้าชม

ผู้เข้าชมสามารถเข้าใจวิธีการใช้งานระบบได้โดยไม่ต้องได้รับคำอธิบายที่ซับซ้อน

การปฏิสัมพันธ์ช่วยสร้างการมีส่วนร่วมกับนิทรรศการ

ผู้เข้าชมสามารถรับรู้ผลลัพธ์จากการกระทำของตนเองได้อย่างชัดเจน

การกระทำของผู้เข้าชมและผลลัพธ์ที่ปรากฏบนหน้าจอมีความต่อเนื่องกัน

ระบบ Interactive ช่วยสนับสนุนประสบการณ์การเข้าชมนิทรรศการโดยรวม

05 — ข้อเสนอแนะ

ท่านคิดว่าส่วนใดของระบบ Interactive ที่ทำงานได้ดีหรือมีความน่าสนใจมากที่สุด

ท่านพบปัญหาในการใช้งานระบบหรือไม่ หากพบ โปรดระบุ

ท่านมีข้อเสนอแนะในการปรับปรุงระบบ Interactive หรือการตอบสนองของระบบอย่างไร

มีข้อเสนอแนะอื่น ๆ ที่ต้องการเพิ่มเติมหรือไม่
